# Template Card Info Resumed

Uma imagem de destaque com um item de lista que tem opção de um link de navegação e um botão. Pode ser repetida 3 vezes.

## Definições gerais

- Não são recomendadas seções sem título.
- Não é recomendado usar apenas o título.
- É possível incluir múltiplas seções.
- É possível usar todos os tipos de item de lista disponíveis no componente Content Line.
- Procure utilizar cards relacionados ao mesmo produto/serviço, como por exemplo, diversas opções de valores para um vale presente ou diversas lojas que possuem cashback.
- Verifique se sua imagem está ajustada. Os cards tem tamanho 500x316.
- O ícone do componente Link Navigation deve ser sempre um chevron.

## UX Writing

Todas as recomendações de writing estão na documentação dos componentes usados no template.

## Card-Icons

Todos os componentes são opcionais.

Na estrutura de Card-Icons, é possível escolher entre carrossel ou vitrine. Se tiver só 2 itens, a largura é ajustada.

- No carrossel: máximo de 6 itens e mínimo de 2.
- Na vitrine (grid): máximo de 3 linhas e mínimo de 2 itens, sendo possível escolher entre 2 ou 3 colunas. Se a quantidade de itens não completar todas as linhas, é mantido um espaço em branco na última linha.
