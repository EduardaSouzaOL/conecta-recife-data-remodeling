# Template Tracking

Uma lista básica de itens, com campos de descrição à esquerda e valores à direita. Para cada item os campos de descrição e valores são opcionais. É possível usar um ícone ou uma imagem e uma subdescrição para cada item.

## Definições gerais

- A seção de **Timeline** é obrigatória, disponível sempre no final do template.
- É possível adicionar múltiplas seções de listas anteriores à seção de Timeline.
- Todos os tipos de item de lista disponíveis no componente Content Line podem ser usados.
- Cuidado ao usar itens de lista diferentes na mesma lista, apesar de ser possível, não é uma boa prática. É preciso observar bem o contexto.
