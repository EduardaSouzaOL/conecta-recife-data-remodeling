# Inner Header (screenHeader)

O Inner Header é uma seção de componentes disponível no início dos templates Kodiak.

## Definições gerais

- O uso do Inner Header não é obrigatório.
- A Tab e o Stepper ou Progress Bar não podem ser usados simultaneamente.
- O título do cabeçalho é obrigatório.
- Deve ser usada a margem de separação de 24px (`$size-space-large`).
- O Inner Header não deve ser usado isoladamente; o template precisa ter algum conteúdo para que o Inner Header possa ser aplicado.

## Boas práticas

- Ao usar o **Progress Bar**, recomenda-se aplicar em seu tamanho menor (Size: Small).

## UX Writing

Para construir o conteúdo deste template, siga as seguintes recomendações:

**Inline Message negocial (azul)** — Mensagens curtas e significativas com informações relevantes para o Negócio.

**Inline Message sucesso (verde)** — Conteúdo referente à finalização de tarefas e ações.

**Inline Message alerta (amarela)** — Informação crítica durante a jornada e que precisa chamar atenção para uma regra de negócio. Exemplo: "Menores de 18 anos não podem ser inseridos".

**Inline Message erro (vermelha)** — Negativa e impeditiva na hora (online). Exemplo: "Não há saldo suficiente para fazer a compra."

Todos os tipos de Inline Message podem trazer um link.

**Tabs** — Defina categorias para serem usadas nas tabs.

**Título principal e subtítulo** — O título deve ser conversacional, pode estar ou não acompanhado do subtítulo. O subtítulo é usado quando há a necessidade de complementar, dar suporte ou esclarecer a informação do título. Sempre usamos pontuação no título e no subtítulo. O sujeito pode ser omitido nas frases, desde que não prejudique a clareza da informação. Preferencialmente, o título tem no máximo 3 linhas e o subtítulo 3 linhas.
