# Inner Footer (internalFooterDLS)

É uma área com seções de componentes disponível no final dos templates Kodiak, salvo algumas exceções.

## Definições gerais

- Seu uso não é obrigatório.
- É composto por seções independentes, não pertencentes aos templates.
- Só é aceito o Info Card Simple.
- Deve usar uma margem de separação de 48px (`$size-space-Huge`).
- O Inner Footer não deve ser usado isoladamente; o template precisa ter algum conteúdo para que o Inner Footer possa ser aplicado.

## Boas práticas

- Não se recomenda o uso de mais de um botão primário na tela. Sendo assim, é desaconselhável o uso do botão primário do Info Card em conjunto com o botão primário do Button Group, fixado no rodapé.

## UX Writing

O Inner Footer pode ser usado em pesquisas que, normalmente, estão no final de fluxos.

**Título principal** — Traz uma pergunta que deve ser respondida através da escolha de estrelas.

**Título secundário** — Deve ser sucinto e oferecer produtos similares ao que foi avaliado na pesquisa.

**Info Card Simples** — Deve ser usado estrategicamente com objetivo claro. O componente não deve fornecer todas as informações, ele precisa mostrar a informação de forma a convidar a pessoa usuária a interagir. Neste Info Card Simples, é sugerido o uso de no máximo 2 linhas para título e 3 linhas para texto auxiliar. Se o componente tiver apenas o título, sem o texto auxiliar, o título pode ter até 3 linhas.
