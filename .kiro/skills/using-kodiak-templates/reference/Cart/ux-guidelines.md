# Template Cart

Uma lista de itens selecionados para compra. Apresenta a imagem do produto, descrição, quantidade e a possibilidade de deletar o item do carrinho de compras.

## Definições gerais

- Pode existir lista de cart sem título.
- Não pode existir título sem lista de cart.
- O cabeçalho interno (Inner Header) é opcional, assim como qualquer componente pertencente a ele.
- O componente botão é obrigatório, já que é um momento de fechamento de compra.
- Não é possível usar as variações do componente Action Line, somente a apresentada.

## UX Writing

Todas as recomendações de writing estão na documentação dos componentes usados no template.
